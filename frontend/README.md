# Jornada Laboral — frontend

React 19 single-page app (Create React App) for the Jornada Laboral work-shift tracker.
Setup, architecture and API documentation live in the [root README](../README.md).

```bash
npm ci
npm start            # dev server on http://localhost:3000
CI=true npm test     # run the tests once
npm run build        # production bundle; set REACT_APP_API_URL to point at the API
```
